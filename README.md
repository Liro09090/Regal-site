# Regal Salon – site

Site de prezentare cu programare online (prin WhatsApp), instalabil pe telefon.

- Datele salonului (adresă, telefon, program, prețuri, poze) se schimbă în `index.html`, la secțiunea `EDITEAZĂ DOAR AICI`.
- Pozele pentru galerie se pun în folderul `poze/`.
- După orice modificare, crește versiunea din `sw.js` (`regal-v1` → `regal-v2`).
